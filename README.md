# An n-Valued Logic System with Graded Implication and Algebraic Contradiction Expulsion

**Author:** Arpan Vohra  
**Original Formulation Date:** September 13, 2025  

## Overview
This repository contains the mathematical paper proposing an $n$-valued logic system constructed over a symmetric integer-valued truth set excluding zero[cite: 1, 2]. 

### Key Characteristics
* **Binary Recovery:** Classical binary logic is recovered exactly as the special case $n=2$[cite: 1, 3].
* **Negation & Operations:** Negation is defined as arithmetic sign-inversion ($\neg A = -A$), while conjunction and disjunction are defined as order-theoretic operators[cite: 1, 2].
* **Algebraic Contradiction Expulsion:** Contradictions are not excluded by external axioms; instead, the assumption of simultaneous truth and negation ($s = -s$) forces $s = 0$, which is structurally excluded from the even-$n$ truth set[cite: 1, 3].
* **Odd-$n$ Extension:** Re-introduces zero as a self-negating state of pure uncertainty that acts as a universal antecedent and consequent[cite: 1, 4].
